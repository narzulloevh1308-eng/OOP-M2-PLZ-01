# Диаграмма действий: Загрузка обучающих данных

```mermaid
flowchart TD
    Start([Начало загрузки]) --> InputData[Эксперт вводит название и загружает данные образцов]
    InputData --> Validate{Данные заполнены корректно?}
    
    Validate -->|Нет| Error[Вывод сообщения об ошибке] --> EndError([Конец с ошибкой])
    Validate -->|Да| Confirm[Подтверждение имени и списка образцов]
    
    Confirm --> Split[Разделение образцов на обучающую и тестовую выборки]
    Split --> Save[Сохранение данных в систему]
    Save --> End([Успешное завершение])
